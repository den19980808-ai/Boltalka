# 📋 Новая функция build_morning_digest()

## 📌 Описание

Функция `build_morning_digest()` полностью переписана согласно требованиям и формирует утренний дайджест строго в следующем формате:

```
🌅 Доброе утро!

📍 Погода:
• Леуварден: 3° → 6° 🌥
• Одесса: 7° → 13° ☀️
• Варшава: -4° → 1° 🌫

🎉 Государственный праздник.
(Если праздников нет — пропускается весь блок)

🎂 Дни рождения:
• Имя — поздравление.
(Если нет — пропускается блок)

🌍 Сегодня в мире:
— Новость 1.
— Новость 2.
(Если нет — пропускается блок)

✨ Отличного дня! Пусть он начнётся легко.
```

## 🔧 Модульная архитектура

### Основная функция
- **`build_morning_digest(target_date: date | None = None) -> tuple[str, dict]`**
  - Возвращает кортеж: (текст_дайджеста, weather_map)
  - Собирает данные со всех источников
  - Работает надежно при отсутствующих данных

### Вспомогательные функции (погода)
- **`build_weather_map() -> dict`** - формирует карту температур
- **`_get_coords_openweather(city_name_en: str)`** - геокодирование
- **`_get_onecall_daily(lat, lon)`** - получение прогноза на день

### Вспомогательные функции (новости)
- **`_collect_world_news(limit: int = 5) -> list[str]`** - сбор новостей из RSS
- **`_is_news_ok(title: str)`** - фильтрация политических новостей
- **`_first_sentence(text: str)`** - обрезка до первого предложения

### Вспомогательные функции (ДР и праздники)
- **`_birthdays_for_today()`** - загрузка ДР на сегодня
- **`build_holidays_section()`** - уже была, интегрирована в `main.py`

## 🌍 Источники данных

### Погода
- **OpenWeatherMap One Call API 3.0**
  - Формат: min → max температуры за день
  - Иконка погоды (☀️ 🌧️ 🌫️ ❄️ ⛈️ и т.д.)
  - Требует: `OPENWEATHER_API_KEY`

### Новости
- **RSS Feeds** (NASA, ESA, Nature, ScienceDaily, MIT Tech Review)
  - Только научно-технические новости
  - Фильтрация политики и военных событий
  - Максимум 1 предложение per новость
  - Не требует ключей API

### Праздники
- **Calendarific API** + **Nager.at** + **API Ninjas**
  - Только гос. праздники Нидерландов, Польши, Украины
  - Расширенный поиск при отсутствии основных праздников
  - Требует: `CALENDARIFIC_API_KEY` или `API_NINJAS_KEY`

### Дни рождения
- **Birthdays.json** (локальный файл)
  - Формат: [{"name": "...", "date": "mm-dd", "year": ...}]
  - Автоматическое вычисление возраста
  - Дружелюбные поздравления через OpenAI

## 🚀 Использование

### В send_digest()
```python
async def send_digest(context: ContextTypes.DEFAULT_TYPE, chat_id: str | int):
    try:
        msg_text, weather_map = build_morning_digest()
        
        photo_desc = ""
        for info in weather_map.values():
            if info and info.get("desc"):
                photo_desc = info.get("desc")
                break
        
        photo_url = get_photo_for_weather(photo_desc or "") or DEFAULT_PHOTO
        
        await context.bot.send_photo(
            chat_id=chat_id,
            photo=photo_url,
            caption=msg_text,
            parse_mode=ParseMode.HTML
        )
        logging.info("✅ Утренний дайджест отправлен")
    except Exception as e:
        logging.error(f"❌ Ошибка: {e}")
```

- Убедитесь, что дата в формате mm-dd или mm-dd-yyyy
